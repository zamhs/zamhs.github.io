GUÍA DEL PROGRAMA

¿Cómo se utiliza?

Cuatro acciones simples para organizar el inventario del negocio.

01

Revisa lo que tienes

En Resumen aparecen las existencias bajas y las ventas del día. En Inventario puedes buscar un producto por nombre o código y revisar su cantidad.

02

Agrega o corrige un producto

Selecciona Agregar producto, escribe un código único, el nombre, los precios y la existencia inicial. También puedes editar el nombre o el precio más adelante.

03

Registra una venta

En Nueva venta selecciona los productos, revisa el ticket y confirma. El sistema calcula el total y descuenta las unidades de manera automática.

04

Repón lo que se agotó

En Inventario elige Reponer mercancía, selecciona el producto y escribe cuántas unidades llegaron. La entrada queda visible en Movimientos.

¿Dónde se guarda?

En este prototipo la información se guarda únicamente en el almacenamiento local del navegador que estás utilizando. No existe una cuenta en la nube ni una base de datos compartida con otra computadora.

Si borras los datos del navegador, podrías perder los cambios. Por eso puedes descargar un archivo CSV con el inventario.

Volver al ejemplo inicial

Si terminaste de probar ventas, entradas y productos, puedes recuperar los datos demostrativos. Esta operación borra las modificaciones de esta copia local.
